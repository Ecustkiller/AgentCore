# 宣传图文案协作说明

本目录存放 AgentCore **9:16 竖版宣传图**的素材、脚本与文案。

## 文件命名规范

```
图{NN}_{主题}.jpg              原始截图
9x16/图{NN}_{主题}_9x16.jpg    9:16 黑边画布
发图文/图{NN}_{主题}_预览.jpg   已定稿文案 · 直接发图文用
```

**编号 = 发图文播放序（方案 B）**，按 `00` → `08` 连发即可。

| # | 文件名 | 画面内容 |
|---|--------|---------|
| 0 | `图00_官网落地` | 官网 Landing Page · 定位开场 |
| 1 | `图01_多方圆桌` | 多方圆桌辩论 · 质检 / 交叉审查 |
| 2 | `图02_正反辩论` | 结构化正反辩论 |
| 3 | `图03_全流程编排` | 一次任务 · 全流程编排 |
| 4 | `图04_画布多轮` | 画布多轮交流协作 |
| 5 | `图05_自动拆解` | 嵌套委派 · 小队并行 |
| 6 | `图06_CEO组队全景` | CEO 组建团队全景图 |
| 7 | `图07_工具箱` | 创作工作台 · 人机共编 |
| 8 | `图08_手机云端并行` | 手机端云端并行 · 收尾 CTA（源图：`apps/promo` `Still-mobile`） |

帖子正文只需极短引导（如 `（3/9）`、收藏提示）；**完整叙事在图上**。

## 脚本

| 脚本 | 说明 |
|------|------|
| `add_letterbox.py` | `图*.jpg` → `9x16/*_9x16.jpg` |
| `render_copy.py` | 白色文案渲染（标题加粗）→ `发图文/*_预览.jpg` |
| `rename_assets.py` | 旧 `mmexport*` → 英文 `fig*`（已完成） |
| `rename_to_chinese.py` | 英文 `fig*` → 中文文件名（已完成） |

## 文案规范

顶部黑边 **4～5 层**，全部 **白色** `#FFFFFF`：

1. **首行加粗**，居中
2. **其余常规字重**，左对齐

层次仅靠字重与对齐区分，不用多色。

字多的图（#0、#3、#4、#5）渲染时建议 `min_letterbox_ratio=0.22`。

## 全部定稿文案

> 以下为方案 B 叙事稿（正文直接上图）。首行加粗，其余常规字重。

### 图 #0 — `图00_官网落地`

- **市面上叫「多 Agent」的产品很多**
- 多数其实是：多模型拼盘、写死的流程图、手动配几个「专家角色」
- AgentCore 想做的不是这些。
- CEO 看任务组队，该并行并行，该辩论辩论，该审查审查
- 后面 8 张图片，逐条展示给你看（内测中欢迎大家免费使用）。

### 图 #1 — `图01_多方圆桌`

- **很多 AI 是：你问一句，它答一句，答完就算交付。**
- 复杂方案呢？开工前先审一遍，过程中有人盯场，
- 交稿前还要多角色交叉看一遍——像项目组过会，不像一个人拍脑袋。
- 这是「多方圆桌」：不是聊天室里多开几个窗口，是有主持、有席次、有审查链。

### 图 #2 — `图02_正反辩论`

- **AI 直接给结论，你不知道它有没有想过反面**
- 这条是「故意有人跟你唱反调」。
- 正方立论、反方驳论、主持人收口——
- 不是抬杠，是把选项辩清楚再决策。
- 技术选型、方案取舍、风险争议，特别适合这一套。

### 图 #3 — `图03_全流程编排`

- **项目一大，聊天框就扛不住了**
- 市场调研、方案辩论、设计架构……
- 谁先做、谁并行、谁等谁——不是你在对话里一步步催，
- 一张编排图里 CEO 自动排期。
- 你下的是目标，团队跑全流程——从调研到决策，不是聊到哪儿算哪儿。

### 图 #4 — `图04_画布多轮`

- **和 AI 聊了几十轮，还记不记得发生过什么？**
- 聊天记录是流水账——越翻越晕。
- 画布是脉络：每一轮对话占一格，
- 改过什么、哪轮派了团队，点进去还能看协作图。
- 从第一个问题到最终方案，一张图往回看，不用考古聊天记录。

### 图 #5 — `图05_自动拆解`

- **不只是一层派发：队员自己还能带队**
- CEO 把大任务交给项目经理；任务再复杂，项目经理还能往下拆，
- 子 Agent 获权后再委派子 Agent，各自小队并行开工，
- 子队产出上卷、队长整合交付——像真公司分工

### 图 #6 — `图06_CEO组队全景`

- **答案就一张图：一个 CEO，按需组队。**
- 辩论、编排、拆解——到底是谁在调度？
- 其它多 Agent：预设几个角色，固定流程走一遍。
- 看任务编席——该谁上谁上，协作关系一张图摊开。
- 你下达目标，按需编排。

### 图 #7 — `图07_工具箱`

- **人和 AI 共用一套创作工作台。**
- 不止 MCP 和动作工具——文档、表格、画布等产物正在补齐。
- Agent 写入，你随手改；同一文件，不是聊完就散。

### 图 #8 — `图08_手机云端并行`

- **不限于电脑前。**
- 通勤、躺床上，一句话把任务扔给云端——
- 多个 Agent 并行开工，你可以锁屏、关 App、甚至关机；
- 跑完了推到你手机上。
- 你现在就能这么用。
