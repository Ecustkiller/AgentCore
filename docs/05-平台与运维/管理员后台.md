# 管理员后台

> **状态**：**P0（用户管理）后端 + 前端 ✅ 已落地**——后端 `/v1/admin/*` API + 独立 web 控制台 `apps/admin`；全站用量看板（P1）/ 系统状态只读（P2）⏳。

面向平台运营者（创始团队）的管理界面。与「设置 → 成员」（仅邀请码）不同，这里管控**跨用户**的账号与平台。

## 一、形态决策：独立 web 控制台（apps/admin）

**决策**：管理后台是**独立 web 应用**（`apps/admin`，React+Vite+Tailwind+shadcn，与桌面同栈，只共享 design-tokens + 生成的 contract-types），**不**塞进桌面端（Electron）。

**为什么（按分量）**：

1. **架构契合**——admin 本质是「`/v1/admin/*` 之上的薄 CRUD 客户端」，不需要桌面端的 sidecar / 本地文件系统 / MCP / inference-token 机制；独立 web 是它最干净的形态。
2. **安全 / 运维**——admin 代码不下发到消费端桌面包；可锁在独立访问路径（内网 only / IP allowlist / 未来 2FA）；独立部署不受 Electron 自动更新滞后拖累；爆炸半径隔离。
3. **零浪费**——后端 `/v1/admin/*` 与前端形态无关，是真边界也是稳定面；独立形态不浪费后端工作，也省掉「从桌面端抽离」的迁移。
4. 与 `cross-platform-frontend` 一致——「各端全新建 + 只共享 contract-types / design-tokens」的又一「端」。

**被否**：A 扩「设置 → 成员」页（设置区窄列放表格挤、admin 代码混入消费端）；B 桌面内 `/admin` 路由（同样混入消费端、背桌面壳）。两者安全增益都只是「换个端口」——真安全取决于访问路径，而非源码放哪个目录。

## 二、鉴权 / 访问姿态（决策）

| 维度 | 决策 |
|---|---|
| 真边界 | 后端 cookie 会话 + `AdminUser`（`role==admin`）→ 403；前端只是客户端 |
| 登录 | **独立登录页**，cookie 限定在 admin origin（不复用桌面会话）|
| 网络 | **内网 only / 不挂公网反代**（独立形态安全价值的大头）|
| 加固 | admin 2FA / 单独凭据 ⏳ P1 |
| CORS | 后端按 admin origin allowlist + credentials |

## 四、后端契约（✅ P0）

`AdminUser` 门控（401 未认证 / 403 非 admin）。

| 端点 | 行为 |
|---|---|
| `GET /v1/admin/users` | 全量名册，`page` / `page_size` 分页 + `q` 子串过滤（username / display_name），含 disabled；newest-first |
| `PATCH /v1/admin/users/{id}` | 部分改 `role` / `status` / 配额。配额**三态**：字段缺省 = 不变 / `null` = 清覆盖回继承全局 / 值 = 设（0 = 该维度不限）|

**护栏（service 层）**：admin 不能改**自己**的 `role` / `status`（防自锁——账号不硬删，唯一通往「零 admin」的路径是最后一个 admin 改自己，故此一条即保证恒有 ≥1 active admin）。停用即时生效：被停用账号下次请求 `get_current_user` 复检 `status` → 401（无需吊销令牌）。

→ 见代码 `api/routes/admin.py`、`admin/service.py`、`db/repositories.py`（`UserRepository.list_all` / `set_status` / `set_role` / `set_quota`）。配额维度语义见 [`成本配额与计费.md`](/docs/05-平台与运维/成本配额与计费.md)。

## 五、前端（apps/admin, ✅ P0）

独立 Vite + React 19 + Tailwind v4 web app（dev 端口 5174，与桌面端零共享业务实现，只共享生成的 contract-types + token 范式）。cookie 登录复用 `/v1/auth/login` → 仅 `role==admin` 进，非管理员落「需要管理员权限」墙。用户管理表格：名册（分页 + 搜索）+ 改角色 + 停用/启用 + 编辑配额弹窗（三态：空=继承/0=不限）；**自己的行禁用角色/状态控件**，与后端防自锁护栏一致。跨 origin 凭据：`credentials:"include"` + 后端 CORS 默认放行 `localhost:5174`（cookie `SameSite=Lax` 同站可携带）。

→ 见代码 `apps/admin/`（`src/services/adminUsers.ts`、`src/pages/UsersPage.tsx`）+ 运行/CORS 说明 `apps/admin/README.md`。
