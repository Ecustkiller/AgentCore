# 本地开发

> **状态**：✅ 已确定

clone 后在本机跑通前后端的最短路径。目录分层与模块边界见 [项目结构](/docs/02-架构/项目结构.md)。

---

## 前置要求

- Python 3.12+
- Node.js 20+
- pnpm 9+
- Docker & Docker Compose
- [uv](https://docs.astral.sh/uv/)（Python 包管理器）

---

## 1. 启动本地基础设施

PostgreSQL、Redis、SearXNG（网页搜索）由开发 compose 提供：

```bash
docker compose -f deploy/docker-compose.dev.yml up -d
```

---

## 2. 启动后端

```bash
cd apps/server
cp .env.example .env          # platform 模式填 PLATFORM_API_KEY 等；BYOK 默认模式登录后在设置页配 key
uv sync                       # 仅运行依赖；跑测试/lint 需 uv sync --extra dev
uv run alembic upgrade head   # 应用数据库迁移（首次启动必做，否则缺表）
uv run python -m agentcore
```

`python -m agentcore` 从 `.env` 读取 `HOST` / `PORT` / `DEBUG`（默认 `0.0.0.0:8000`，`DEBUG=true` 时热重载）。与 VS Code 自动启动任务一致。改了数据模型（新增迁移）后重跑 `uv run alembic upgrade head` 即可。

### 初始账号

注册已开放（无需邀请码）。空库可直接在登录页注册，或用脚本预置：

```bash
# 管理员（密码交互式输入，或用 ADMIN_PASSWORD 环境变量传入）
uv run python scripts/create_admin.py <username>

# 开发用普通账号（默认 dev / devpassword，配合桌面端 .env.local 自动登录）
uv run python scripts/seed_dev_user.py
```

紧急关闸：环境变量 `REGISTRATION_OPEN=false`（见 [`认证与会话.md`](/docs/05-平台与运维/认证与会话.md)）。

## 3. 启动前端

```bash
cd apps/desktop
pnpm install
pnpm dev
```

### 手机端 web（`apps/mobile`）

```bash
pnpm -C apps/mobile dev
```

- 本机：`http://localhost:5175/`
- **真机 LAN**：同一 WiFi 下打开 `http://<开发机局域网 IP>:5175/`（Vite `host: true`）。API 走同源 `/api/*` 反代到 `localhost:8000`，**无需**改 CORS 或 `.env.local` 填 IP。
- **离线看 UI 态**：`http://localhost:5175/preview`（或 `?s=<向量名>`）回放 conformance 向量，零后端。截图：`pnpm -C apps/mobile shot http://localhost:5175/preview?s=single_agent_tool`
- 可选：`apps/mobile/.env.local` 里配 `VITE_DEV_USERNAME` / `VITE_DEV_PASSWORD`（先 `seed_dev_user.py`）自动登录；跨域验收走 staging / Pages preview，不在 LAN dev 里测。

## 4. AgentTown（Unity 小镇观测客户端）

AI 小镇的 3D 观测层是**独立 Unity 6 客户端** `apps/town`（Desktop 仅作启动器，不内嵌 3D）。本项目开发机已具备 Unity 环境，clone 后可本地打开 / 构建 / 截图自检——改小镇相关代码可本地验证。

- 前置：Unity 6000.0.78f1 + WebGL/Windows Build Support（一键 `pwsh apps/town/scripts/install-unity.ps1`）
- 打开工程 `pnpm town:open`；逻辑冒烟 `pnpm town:verify`（EditMode+Play，须先关 Editor）
- **离线自检（无后端 / 无 LLM）**：`pnpm town:serve:webgl` 浏览器跑 `?demo=1` Offline Demo；`pnpm town:shoot:webgl` 三剧本包截图 → `apps/town/shoot-out/*.png`
- 连后端（无 DeepSeek 自动走 scripted）：后端 `SIMULATION_ENABLED=true` → Play → 新建 Run（默认 `scripted:true`）→ Advance Tick

**Desktop → AgentTown scripted 开箱（无真实 LLM）**

1. 后端 §2 已起且 `SIMULATION_ENABLED=true`；`cd apps/server && uv run python scripts/seed_dev_user.py`（`dev` / `devpassword`）
2. 构建 Unity 客户端：`pnpm town:build` → `apps/town/Builds/Windows/AgentTown.exe`
3. Desktop：`pnpm -C apps/desktop dev` → `#/simulation/town` → **新建小镇**（默认 scripted）→ **在 AgentTown 中打开**（写 `session.json` + `--run-id`）
4. HTTP 冒烟（创建 scripted run → tick → SSE/持久化，无需 DeepSeek）：
   ```bash
   pnpm -C apps/desktop sim:smoke:e2e
   # 仅验 REST+SSE、不推进 tick：pnpm -C apps/desktop sim:smoke:e2e:mock
   ```

完整命令 / CLI / `session.json` / 坐标契约 → [`apps/town/README.md`](/apps/town/README.md)。

## 排障：`read_url` / `web_search` 全失败（本机代理 fake-IP）

**症状**：开发机上 `read_url` 每次瞬间（~1ms）返回 `[ERROR] 链接解析到私有/保留地址，已按 SSRF 防护拦截`，`web_search` 超时或返回英文噪音——即便公网正常、对照域名（`baidu.com` / `gov.cn`）也一样。

**根因**：本机**本地代理 / VPN 的 fake-IP 模式**（Clash / Mihomo / Surge / v2rayN 默认 `fake-ip-range = 198.18.0.0/16`）把**所有**域名 DNS 应答成 `198.18.0.x`（RFC 2544 保留段）；应用「自解析 DNS + Pin IP」的 SSRF 守卫（`core/net.py`）判其为保留段 → **正确拦截**。**非产品缺陷、非 ISP 劫持；生产服务器无此代理、不受影响**（SSRF 保持严格是有意决策、不为 dev 放宽——见 [安全权限与治理 §一](/docs/05-平台与运维/安全权限与治理.md)）。

**诊断**（一条命令，`apps/server` 下）：

```bash
uv run python scripts/probe_egress.py
```

看汇总行 `fake-IP 检出: YES` + 每条 `DNS -> …198.18.x.x(FAKE-IP)…` 即坐实（脚本走应用同路径 `_getaddrinfo` + `classify_url` + 真 `read_url`）。

**解决**（人操作，二选一）：

- **首选·把代理 DNS 从 `fake-ip` 改成 `redir-host`**（保留代理、只换 DNS 策略）：Clash / Mihomo 配 `dns.enhanced-mode: redir-host`（或整体关 `dns.enable`）重载；v2rayN 关「FakeDNS / fake-ip」；Surge 移除 `[General]` 的 `fake-ip` 项或用 `always-real-ip`。
- **或·临时让后端不走代理 DNS**：关 TUN / 系统代理，或只代理 HTTP(S) 不劫持 DNS，让 `getaddrinfo` 落真实公网 IP。

**复验**：再跑 `probe_egress.py`，出现 `=> PASS：DNS 落真实公网 IP、SSRF 放行、read_url 端到端可读` 即恢复。**环境会漂移**，跑辩论 / 用取证前先复验。
