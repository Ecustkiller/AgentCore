# 本地开发

> **状态**：已确定

clone 后在本机跑通前后端的最短路径。目录分层与模块边界见 [项目结构](项目结构.md)。

---

## 前置要求

- Python 3.12+
- Node.js 20+
- pnpm 9+
- Docker & Docker Compose
- [uv](https://docs.astral.sh/uv/)（Python 包管理器）

---

## 1. 启动本地基础设施

PostgreSQL、Redis、SearXNG（网页搜索）由开发 compose 提供：

```bash
docker compose -f deploy/docker-compose.dev.yml up -d
```

---

## 2. 启动后端

```bash
cd apps/server
cp .env.example .env   # 至少填写 DEEPSEEK_API_KEY
uv sync
uv run python -m agentcore
```

`python -m agentcore` 从 `.env` 读取 `HOST` / `PORT` / `DEBUG`（默认 `0.0.0.0:8000`，`DEBUG=true` 时热重载）。与 VS Code 自动启动任务一致。

---

## 3. 启动前端

```bash
cd apps/desktop
pnpm install
pnpm dev
```

---

## 常用命令

```bash
# 后端
cd apps/server
uv run python -m agentcore    # 开发服务器
uv run pytest               # 测试
uv run ruff check .         # lint

# 前端
cd apps/desktop
pnpm dev                    # electron-vite 开发模式
pnpm test                   # Vitest
pnpm build                  # 构建

# 类型同步（OpenAPI → TypeScript）
cd packages/scripts
pnpm generate-types
```
