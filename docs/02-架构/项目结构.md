> **状态**：✅ 已确定

## 一、总览

Monorepo 布局，前后端统一管理：`apps/server`（Python/FastAPI）、`apps/desktop`（Electron + React）、`apps/admin`（独立运营控制台，详见 [`管理员后台.md`](/docs/05-平台与运维/管理员后台.md)）；`deploy/` 为 compose 与环境模板；`docs/` 为设计文档。

→ 见代码：`apps/server/agentcore/`、`apps/desktop/src/`。OpenAPI 类型同步 → 见 [本地开发.md](/docs/02-架构/本地开发.md)。

本文只记录目录树看不出来的**分层边界**与非显然依赖。

---

## 二、后端分层（apps/server/agentcore）

> 目录与文件清单 → 见代码：`apps/server/agentcore/`。模块体系与 runtime 子包见 [`后端架构.md`](/docs/02-架构/后端架构.md)。下表只记录**非显然依赖约束**。

| 模块 | 不依赖（硬约束） |
|------|------------------|
| `api/` | runtime, llm, tools（HTTP 入口只经 schemas + service） |
| `runtime/` | conversation, api |
| `llm/` | 所有其他业务模块 |
| `tools/` | 所有其他业务模块 |
| `memory/` | db, runtime（记忆维护走文件 + llm，不经 runtime 回路） |
| `db/` | 所有其他业务模块 |
| `core/` | 所有其他模块（共享类型，零向上依赖） |

### 调用链路

→ 见代码：`conversation/service.py`（`stream_chat` 入口）+ `runtime/pipeline.py`。
