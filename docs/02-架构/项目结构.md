# 项目结构

> **状态**：✅ 已确定

---

## 一、总览

Monorepo 布局，前后端统一管理：`apps/server`（Python/FastAPI）、`apps/desktop`（Electron + React）、`apps/mobile`（Vite SPA + Capacitor，Bearer 鉴权）、`apps/admin`（独立运营控制台，详见 [`管理员后台.md`](/docs/05-平台与运维/管理员后台.md)）；根级 `packages/`（跨端规范与契约，非业务实现）；`deploy/` 为 compose 与环境模板；`docs/` 为设计文档。

→ 见代码：`apps/server/agentcore/`、`apps/desktop/src/`、`apps/mobile/src/`、`packages/`。OpenAPI / SSE 类型同步 → 见 [本地开发.md](/docs/02-架构/本地开发.md)。

本文只记录目录树看不出来的**分层边界**与非显然依赖。

## 三、跨端共享包（packages/）

pnpm workspace 纳入 `packages/*`、`apps/desktop`、`apps/mobile`、`apps/admin`（→ 见根 `pnpm-workspace.yaml`）。**共享的是规范 / 契约，非业务实现**（各端 stores / services / fold / 组件各自全新建）。

| 包 | 职责 |
|---|---|
| `protocol-conformance` | SSE 测试向量 + golden harness + `ProjectedTurn` schema |
| `contract-types` | SSE 事件判别联合（`events.ts`）；理想态后端 schema 生成 |
| `contract-rest-types` | OpenAPI 生成 REST 类型（desktop / admin / mobile 共享单一源） |
| `design-tokens` | 跨端语义色 token |

协议 fold 对账：根目录 `pnpm conformance`；后端 golden 重导 `python -m agentcore.conformance.export`。→ 见 [`前端技术与架构.md` §十二](/docs/04-前端/前端技术与架构.md)、`.cursor/rules/protocol-conformance.mdc`。

## 四、手机端（apps/mobile）

独立 Vite + React 应用：自有 stores / services / 协议 fold / 组件；鉴权走 Bearer（非 cookie）。Capacitor 8 套壳（Android 工程已 scaffold）；web 版已部署 Cloudflare Pages。→ 产品减法与跨端策略见 [`前端技术与架构.md` §七](/docs/04-前端/前端技术与架构.md)；原生壳 / 商店余项 → [`远期规划`](/docs/07-规划/远期规划.md) §3.2。

## 七、包管理与工具链

根级 **pnpm workspace**（`packages/*` + `apps/desktop` + `apps/mobile` + `apps/admin`）；后端 **uv**。跨端门禁 `pnpm conformance`（CI mobile job + 本地可串桌面 vitest）。REST 类型单一源：根 `pnpm gen:types` → `@agentcore/contract-rest-types`（desktop/admin/mobile 经 shim re-export）。其余工具链见各包 manifest 与 CI（Biome / Ruff / Vitest / pytest / Alembic 等）。
