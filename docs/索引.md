# AgentCore 文档索引

设计文档总入口。文档按主题分组（`01` → `07`），数字前缀仅表示阅读/概念顺序，无强制依赖。

> **定位**：`docs/` 是项目知识资产（What/Why，给人 + AI 读）；`.cursor/rules/` 是 AI 行为指令（How）。文档是**现状说明书**而非变更日志——只记录代码看不出来的决策、理由与约束。详见 `.cursor/rules/doc-governance.mdc`。

## 状态图例

- ✅ 已落地：代码已实现
- ⏳ 已确认未落地：方向已定、代码未实现（可出现在 `01`–`06` 蓝图，或 `07-规划`）
- 🗂️ 讨论提案：未必落地——**仅 `07-规划`**

> 现状目录（`01`–`06`，含本文件正文）= 已落地现状 + 已确认的目标架构蓝图；🗂️ 纯提案一律放 `07-规划`。详见 `.cursor/rules/doc-governance.mdc`。
