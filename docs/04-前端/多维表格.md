# 多维表格

> **已卸**。人侧 `/tables` 编辑器与 Agent `table_*` 一并卸下。工作区 `.csv` 当文件打开，不再灌活表。下文是卸前规格，**不是现行产品**。

> **主循环归属**（卸前）：支线**创作工具**，服务「收」。

桌面内页面（非独立 app）。服务端为数据与视图真相。→ `apps/desktop/src/renderer/tables/` · `apps/server/agentcore/table/`。冲突以代码为准。

## 定位

工具箱里一张带类型列的表：人原地改格子。编辑器不提供说话入口。

**只做创作产物**。不是工作台列表壳。csv 可以**灌数**（✅）；文件 / 对话不能当活数据源。

## 关键决策

| # | 决策 |
|---|---|
| 形态 | 深页 `/tables` → `/tables/:id`；工具箱 · 创作入口，**不**进侧栏主导航。壳用 `CanvasShell`（返回 + 标题）。列表/编辑器有种子路径时标出工作区 csv。工作区点已灌数的 `.csv` 进活表（未灌仍当文件；不拦 git）。表内工具栏分区：新建/命名视图 · 筛排分/查找 · 显示模式/字段/溢出（密度、导出 CSV）。编辑器无 AI 铬条（无底栏发送条、无「问 Agent」/「打开对话」），不发起回合 |
| 归属 | **账号级**（照白板）。列表只返回所有者的表。v1 **不**挂文件夹、**不**与协作桌共编 |
| 真相 | **服务端**（照文档，不照白板）。人没打开表时 REST 仍能改行。**禁止**把写行做成 `BoardChannel` / CLIENT_TOOL |
| 存储 | 另起 `tables` / `table_rows` / `table_views`。列定义 `schema_version` CAS；格子 last-write-wins。行顶 5000，超顶诚实失败 |
| 字段 | 闭集：`text` / `number` / `singleSelect` / `multiSelect` / `date` / `datetime` / `checkbox` / `url`。筛/排/分由类型派生 |
| 视图 | 服务端为真相。四种显示模式：`table` / `kanban` / `calendar` / `gallery`。字段不够 → 配置修复态，禁止「即将上线」占位卡。看板拖卡片写回分组列；日历 v1 不做拖改日期 |
| AI（⏳） | 人编辑器经 REST `apply_ops`。无 Agent 表格工具。本回合落盘 `.csv` 仍自动灌数。编辑器不发起回合。L2/L3 dryRun 确认后再落库；批次可整批撤销。零新编排 / 零新 fold |
| 端 | 仅桌面宽屏（窄屏黑名单与白板/文档/工具箱同条） |

## ✅ CSV 灌数与主对话共编

活表仍是库；csv 只负责进出和灌数；xlsx 不当进口。

- **自动建表**：本对话本回合成功落盘的 `.csv` → 快照导入成账号级表。同一工作区路径再写 → 覆盖同一张表。不扫用户原文猜要不要建表。附件 csv 默认不自动建。
- **打开即表**：工作区（文件页 / 对话产物）点已灌数的 `.csv` → `/tables/:id`。未灌数或 `attachments/` 仍开文件。git 变更点路径仍开文件。
- **种子路径**：列表卡片与编辑器顶栏标出 `source_path`（有才显示）。
- **共编入口**：只有主对话。人 `@` 那个 csv（不新开 `@` 表格分类）仍绑定活表、注入 `<表格>` 事实。再 `write` 该 csv 会整表覆盖灌数，不是改格子。无 Agent 改格工具。
- **不做什么**：编辑器底栏 / 「问 Agent」；以表会话为主入口；新造第三套表格工具；Excel 上传导入。

## 否决

文件/对话当表格**活** Source（导入快照 ≠ 挂载）；`folder_id` 废列；公开分享 / 文档或白板内嵌 TableRef；公式 / JOIN / 自动化规则；整表 JSONB + 整表 CAS；行详情页；日历拖改日期；`relation` / `attachment` / `person` / `computed`；Excel 上传导入；窄屏装配；新 InteractionKind；把写行做成白板 Channel；编辑器底栏发送条（无时间线的假 composer）。表格**不**另起无限画布。白板引擎已卸 → [AI 协作白板](/docs/04-前端/AI协作白板.md)。

## ⏳ 另案

钉到文件夹 / 协作桌共编；公开分享；文档内嵌 TableRef。要开另等人确认。
