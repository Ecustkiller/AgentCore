## 一、终态不变量（P3 仍须遵守）

1. **引用 = 成稿实际引用的来源**；未引用的检索命中是「检索痕迹」，不自动挂主卡（✅ P2）。
2. **每条引用可溯源到统一登记条目**（台账 id；✅）。
3. **质量用 tier 透明展示，而非悄悄过滤**；`weak` 可被显式引用并带弱源徽标（✅ P2）。
4. **机械闸只查可机械判定的事**：id 存在性（✅）。关键主张须证 → **P3**；回源对照正文 → **另案不做**。
