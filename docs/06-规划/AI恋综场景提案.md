# AI 恋综场景提案（传播钩子）

> **状态**：🗂️ 产品定案（2026-07-09起持续补齐；**2026-07-10** 人设定稿 + **排期策略：先最小可播 demo，不改小镇主线**）——**尚未**拆完整开发任务、未改 `simulation/` / AgentTown 总优先级。
> **关联**：[多 AI 模拟愿景](multi-ai-simulation-vision.md)、[AI 小镇 MVP](AI小镇MVP开发计划.md)、[AgentTown 客户端规格](AgentTown客户端规格.md)
> **定位**：用「观众向 AI 恋综」作为多 AI 模拟的**对外传播钩子**；小镇/通用模拟引擎仍是中长期世界，不抢第一印象。

---

## 1. 为什么做

现有 AI 小镇叙事（好看 3D + 观察涌现 + 上帝旋钮）对路人吸引力偏弱：缺角色弧、缺悬念、缺「我站谁」的情绪钩子。

**恋综**提供更硬的观看动机：好磕、好骂、好猜、好剪。引擎仍可复用模拟层（人设、动机、交互、tick/期、回放）；对外包装从「社会沙盘」改为「一季节目」。

---

## 2. 已确认决策

| # | 问题 | 定案 |
|---|------|------|
| 1 | 尺度 | **甜虐为主 + 轻度撕逼**；不做纯甜宠、不做纯撕逼 |
| 2 | 内容底线 | 公开舞台向：拉手 / 告白 / 吃醋 / 当众拒绝 / 冷战 ✅；性暗示、羞辱、人身攻击、极端仇恨 ❌。原则：**观众席可起哄，角色不能下作** |
| 3 | 品牌关系 | **对外第一句话 = AI 恋综**；小镇是舞台/更大世界。双入口心智（传播用恋综，深度/对内仍可称模拟），执行上第一季按恋综封闭场景做，不做「开放小镇里稀释一条恋爱线」 |
| 4 | 用户角色 | **观众**，不是恋爱对象、不扮演季内角色实时聊天 |
| 5 | 参与 | **每期竞猜标配** + **整季仅 1 次公投（第 5 期）**；用户投稿人设进季 → 第二季再议 |
| 6 | 第一季体量 | **6 人（3+3）· 7 期**；节拍半写死保证每期有戏，LLM 填对白与选择保证季间分叉 |
| 7 | 验收 | 陌生人是否看完一期、是否出现站队/转发切片；**不**用宏观社会指标验收好看 |
| 8 | 冷启动 | **先戏后规则**：默认进「本季正在播的一期」或「第 3 期级名场面切片」→ 再追整季；不做先读规则/先配人设 |
| 9 | 赛制一句话 | 每晚每人选一个心动；互相选中 → 配对成功；连续两期零票 → 离场；第 7 期结局夜收束 |
| 10 | 心动公开 | **半公开**：先写下 → 夜话可试探 → **期末统一揭晓** |
| 11 | 配对后移情 | **允许，但有代价**（公开「移情」标记，并占用一次名场面）；不做配对即锁死到结局 |
| 12 | 公投窗口 | **第 5 期**（三选一：保人 / 公开某人心动 / 强制一次约会） |
| 13 | 第 1 期 | **无教学期**：直接按正式赛制跑；规则用 HUD 一行字带过 |
| 14 | 七期情绪弧 | 1 亮相 → 2 火花 → 3 不对劲 → 4 告急/移情苗头 → **5 公投夜** → 6 洗牌 → 7 结局夜 |
| 15 | 竞猜 | 每期主猜「焦点角色今晚选谁」；夜话后、揭晓前插入；结算 = 对错 + 一句独白回放；无积分商城 |
| 16 | 季末钩子 | 结局后三出口：本季高光片 / 同开局另一分叉 / 预告下一季阵容；不做强绑「立刻自己开一季」 |
| 17 | 第一季观看壳 | **轻量 Web 播放器优先**（追一期 + 竞猜 + 切片）；AgentTown 3D 为加分/后置，不挡传播 |
| 18 | 角色落笔顺序 | **先关系拓扑，后姓名职业**；§3.5 功能位 + 拓扑为戏剧骨架；人设用**三行卡**（公开 / 秘密 / 动机） |
| 19 | Web 播放器信息架构 | **只五面**：落地续看 / 播控期 / 竞猜打断 / 期结 / 季末；无实验仪表盘、无居民大全、无常驻上帝面板 |
| 20 | 第一季人设 | **现代都市 · 三行卡已定稿**（沈晚/陆野/许安安/蒋予/周可/谢衡）；可改称呼用字，**不改拓扑与三行动机** |
| 21 | 七期节拍分工 | **写死：事件义务 + 约会配对 + 竞猜焦点 + 必须露出的信息**；**LLM：台词、微观反应、心动选票（在约束内）**；不写死最终谁和谁结局 |
| 22 | 五面线框原则 | 一屏一事；播放中信息 ≤3 层；竞猜/公投全屏打断；无侧栏堆面板 |
| 23 | 排期策略 | **先做最小可播 demo 验吸引力，不改小镇/AgentTown 总主线**；demo 过关后再拍是否插队完整恋综 Web |

### 一句话

> 对外是甜虐向 AI 恋综；用户是观众（竞猜 + 每季一次公投）；小镇是更大世界，不抢首发心智；尺度停在节目级暧昧与冲突。

### 明确不做（第一季）

- 用户扮演男/女主或与 AI 私聊谈恋爱（切开「AI 女友」赛道）
- 开放世界小镇日常里「顺便恋爱」（焦点被冲淡）
- 高频上帝乱点 / 全程操控单个角色
- 狼人杀式陪玩（赛道挤；与「观察 + 轻参与」不符）
- 冷启动先塞规则说明或自定义开局
- 配对后锁定到结局（少反转）；心动全程当场公开（泄悬念）或全程保密（观众难跟）
- 复杂积分、多人混战投票淘汰、观众给角色「加攻略值」
- 单独教学期 / 第 1 期降级规则
- 竞猜积分商城、排行榜重运营（第一季只保留对错即时反馈）
- Web 壳做成模拟器后台（仪表盘 / 属性大全 / 常驻上帝模式）

## 3. 产品形态

### 3.1 心智

| | AI 陪聊/女友 | **本提案：AI 恋综** |
|---|---|---|
| 用户 | 恋爱对象 | **观众 / 偶发公投** |
| 戏 | 你与 AI 私聊 | **AI 之间的关系网** |
| 传播物 | 聊天截图 | 名场面、站队战报、结局分叉 |

定位句（对外可用）：**一季 AI 真人秀——你不谈恋爱，只负责磕、骂、猜、投票。**

### 3.2 冷启动（前 60 秒）

用户心智是**追节目**，不是用工具。

1. 落地 → 直接播**正在发生的戏**（优先：本季当前期；若无进行中季，则播预置「第 3 期级」名场面切片）
2. 片尾钩子：「今晚 TA 会选谁？你猜对了吗」→ 竞猜或续看
3. 再提供：追本季 / 高光合集 /（后置）自己开一季

不做：先读完整规则、先配人设再开跑。

### 3.3 一季结构与赛制

**舞台**：封闭营地/别墅（不必先做开放小镇地图）。

**班底**：6 人；每人 = 公开人设（观众可见）+ 私心/秘密（角色与系统可见）；关系含心动对象、防备、同盟、黑历史。戏剧功能配比见 §3.5。

**一期 = 一个「夜」**（对内可映射若干 tick；对外只叫「第 N 期」），固定四拍：

1. 白天任务/约会（两人一组，回屋复盘）
2. 篝火/客厅夜话（公开表态、试探——名场面高发）
3. 心动选择（写下今晚心动；半公开，期末揭晓）
4. 仪式节点（双选配对 / 移情标记 / 零票累计 / 离场等）

**赛制细则（第一季）**

| 规则 | 定案 |
|------|------|
| 心动 | 每晚每人选且仅选一人 |
| 配对 | 互相选中 → 配对成功 |
| 移情 | 配对后仍可选别人，但触发公开「移情」标记 + 名场面 |
| 离场 | 连续两期零票离场（第 7 期用结局夜收束，不套此条） |
| 公投 | 仅第 5 期一次：保人 / 公开某人心动 / 强制一次约会 |
| 结局夜 | 已配对：是否确认关系；未配对：最后心动 + 一句独白 |

**七期情绪弧（半写死节拍；对白/选择可分叉）**

| 期 | 情绪任务 | 观众该有的感觉 |
|----|----------|----------------|
| 1 | 亮相 + 第一次心动试探（正式赛制，无教学） | 「这几个人有点意思」 |
| 2 | 第一对约会出火花 | 开始站队 |
| 3 | 夜话第一次不对劲（误会/试探） | 想骂 / 想磕 |
| 4 | 有人零票告急或移情苗头 | 紧张 |
| **5** | **公投夜** + 后果当场显现 | 「都是我们投的」 |
| 6 | 公投余波 + 结局前最后洗牌 | 不敢快进 |
| 7 | 结局夜 | 哭/骂/转发 |

### 3.4 观众动作

| 动作 | 第一季 |
|------|:------:|
| 看公开互动 + 内心独白（上帝视角） | ✅ |
| 本集高光一键回看 | ✅ |
| 「今晚 TA 会选谁」竞猜并结算 | ✅ |
| 全季 1 次公投（第 5 期） | ✅ |
| 扮演角色 / 实时私聊 | ❌ |
| 投稿人设进季 | ⏳ 第二季 |

### 3.5 六人戏剧功能与三行卡（已定稿）

功能位 + 拓扑 + 三行卡已于 2026-07-10 人确认通过。目标：甜虐可磕、有搅局、有镜子，避免六人同质恋爱脑。第一季 **3 女 3 男**。

| 位 | 戏剧功能 | 观众预期 |
|----|----------|----------|
| A | 外热内冷、慢热真香 | 主磕之一 |
| B | 直球心动、行动派 | 与 A 或 C 形成张力 |
| C | 温柔但回避承诺 | 甜虐高频源 |
| D | 搅局者（不是恶人：好奇/好胜/怕无聊） | 制造三角与名场面 |
| E | 理性观察型（会说破、少下场） | 观众代言人、复盘嘴替 |
| F | 暗线/秘密持有者（与某人有未公开过往） | 中后期反转燃料 |

**第一季关系拓扑（已定）**

```text
主磕线：  A ←紧张吸引→ B
暗恋线：  C →（单向心动）→ B
搅局：    D 切入 A–B（试探/抢约会/夜话拱火），不预设「真爱」
嘴替：    E 少下场，说破场上气氛；可对一人有淡淡好感但不抢主线
暗线：    F ↔ C 有未公开过往（第 4–6 期逐步露）
第二磕苗头：C–F 旧情复燃 vs C→B 的拉扯（甜虐第二引擎）
```

| 边 | 开局状态 | 戏剧用途 |
|----|----------|----------|
| A–B | 互相有感觉但 A 慢热、B 更直 | 主站队、双选悬念 |
| C→B | C 心动，B 未必同等 | 三角、吃醋、误会 |
| D→A–B | D 主动搅，动机是怕无聊/好胜 | 名场面，非纯恶人 |
| E | 观察为主 | 复盘、帮观众读空气 |
| F–C | 旧过往未公开 | 中后期反转；与 C→B 抢戏 |

**三行卡（2026-07-10 定稿）**

| 位 | 姓名 | 公开（观众可见） | 秘密（角色+系统） | 动机（一句人话） |
|----|------|------------------|-------------------|------------------|
| A 女 | **沈晚** | 独立设计师，嘴上什么都行，靠近就退 | 其实怕认真喜欢的人看穿自己没那么酷 | 「想靠近，但更怕先动心的人是我。」 |
| B 男 | **陆野** | 创业早期，做事直、约会也直 | 对优柔寡断没耐心，却被沈晚的退缩勾住 | 「喜欢就说；不喜欢也说清楚。」 |
| C 女 | **许安安** | 温和编辑，好说话，从不让场面难看 | 心动陆野，同时躲着未了结的旧关系 | 「我想被选中，又不敢承诺谁。」 |
| D 男 | **蒋予** | 爱起哄的自由职业，场上气氛发动机 | 不是来真爱的，是来证明「我也能搅动局面」 | 「太平静的夜晚，我会亲手弄出点浪。」 |
| E 女 | **周可** | 咨询顾问，话少但准，像场外解说 | 对陆野有一点好感，选择不当众下场 | 「我看清了，不代表我要下场抢。」 |
| F 男 | **谢衡** | 沉稳工程师，礼貌、难读 | 与许安安有一段未公开、未好好结束的过往 | 「我不是来复合的——除非她先回头。」 |

**改拓扑需再开产品讨论**；仅微调称呼用字可以，不偷偷改关系边。

### 3.6 一期信息架构（观众看到什么）

同一时间线叠三层，默认不关戏：

| 层 | 内容 | 默认 |
|----|------|------|
| 舞台 | 约会/夜话/仪式的公开言行 | 始终开 |
| 独白 | 当前焦点角色的内心一句（可切换角色） | 开；可关 |
| 关系微条 | 谁对谁「心动倾向」的模糊信号（非精确数值） | 开；揭晓前不剧透最终选择 |

**竞猜（第一季）**

| 项 | 定案 |
|----|------|
| 主问题 | 「今晚 **焦点角色** 会选谁？」（每期系统指定 1 个焦点，降低选择疲劳） |
| 插入点 | 夜话结束 → **暂停竞猜** → 心动揭晓 → 对错结算 |
| 结算 | 对/错即时反馈 + 回放该角色**一句相关独白**（强化「我懂/我看走眼了」） |
| 不做 | 积分商城、赛季排行榜、猜错惩罚扣次数 |

可加一道轻量副猜（可选）：「今晚会不会出现移情/双选？」——二元题，不挡主流程。

**高光**：期结束后自动生成 3 条候选（最毒一句 / 最大反转 / 最甜瞬间），可一键重看或分享。

### 3.7 季末与回访

结局夜播完后，只给三个出口（均不强迫）：

1. **本季高光片**（自动剪的 60–90 秒）→ 主传播物  
2. **同开局另一分叉**（换种子再跑一季）→ 体现 AI 差异、满足「如果当时…」  
3. **下一季阵容预告**（可先是预告卡，未必已生成）→ 回访钩子  

第一季**不强绑**「立刻自己开一季 / 投稿人设」——那是工具心智，冲淡节目余韵。

### 3.8 AI 必须贡献的差异（否则只是短剧换皮）

1. 同一开局，不同季结局可分叉（种子可复现，可宣传对照）
2. 内心独白 ≠ 当面台词
3. 关系转折由动机+规则推出，而非纯编剧写死每一集结局
4. 可自动抓「本集最毒一句 / 最大反转」做切片

生成策略：**节拍半 scripted + LLM 填对白与选择**——先保证每期有戏，再逐步加重真涌现。

### 3.9 轻量 Web 播放器：只五面

第一季观看壳 = **节目播放器**，不是模拟控制台。

| # | 面 | 用户在做什么 | 有 | 无 |
|---|-----|--------------|----|----|
| 1 | 落地 / 续看 | 点开就进戏或名场面切片 | 续看本季、切片入口 | 规则长文、配人设开局 |
| 2 | 播控期 | 追当天四拍 | 舞台 + 独白 + 关系微条 + 一行赛制 HUD | 属性面板、实验指标 |
| 3 | 竞猜打断 | 夜话后选边 | 焦点角色「会选谁」 | 多题问卷、积分商城 |
| 4 | 期结 | 看揭晓与余韵 | 心动揭晓、对错+独白、高光 3 条 | 长复盘报告 |
| 5 | 季末 | 收束与传播 | 高光片 / 同分叉 / 下季预告 | 强推「自己开一季」 |

**公投**：不占常驻面；仅第 5 期在「竞猜打断」位升级为**一张公投卡**（三选一），投完回播控看后果。

### 3.9.1 五面线框（一屏一事）

原则：手机竖屏优先（传播默认可转发）；桌面居中同构。播放中**不同时**塞属性表、时间轴总览、实验指标。

#### 面 1 · 落地 / 续看

```text
┌─────────────────────────────┐
│  季标题 · 第 N 期进行中      │
│                             │
│   [ 自动起播：切片/续看 ]    │
│                             │
│  主 CTA：继续观看            │
│  次：高光合集 · 本季简介     │
└─────────────────────────────┘
```

| 有 | 无 |
|----|----|
| 自动进戏或第 3/5 期级切片；一行「本期看到哪」 | 规则长文、登录墙挡第一口戏、配人设 |

#### 面 2 · 播控期（默认态）

```text
┌─────────────────────────────┐
│ 第3期 · 夜话  一行赛制HUD   │
│                             │
│        舞台区（主视觉）      │
│     对白/动作字幕可选        │
│                             │
│ 独白：「…」  ←可切换角色     │
│ ░ A━B ░ 关系微条（模糊）    │
│ [暂停] [倍速]  · 进度点     │
└─────────────────────────────┘
```

| 有 | 无 |
|----|----|
| 舞台 + 独白（可关）+ 关系微条 + 一行 HUD + 简单播控 | 六人属性卡、上帝按钮、侧栏事件流、实验图表 |

切换角色独白：点关系微条上的人，或舞台点击角色——**不**开新页面。

#### 面 3 · 竞猜打断（全屏）

```text
┌─────────────────────────────┐
│ 今晚 · 焦点：许安安          │
│ 她会选谁？                   │
│                             │
│  [ 陆野 ]  [ 谢衡 ]  …      │
│                             │
│  选完 → 立刻回揭晓动画       │
└─────────────────────────────┘
```

第 **5** 期同位置换成公投卡：

```text
┌─────────────────────────────┐
```

### 3.10 七期逐期节拍（写死 vs LLM）

**分工原则**

| 写死（保证每期有戏） | LLM（保证季间不同） |
|----------------------|---------------------|
| 本日事件义务（必须发生的戏剧节拍） | 具体台词、语气、玩笑/阴阳的措辞 |
| 白天约会**谁和谁一组**（或候选池） | 约会里谁更主动、空气怎么冷/甜 |
| 本期竞猜焦点角色 | 独白措辞；选票在**允许集合**内选择 |
| 必须露出/不得剧透的信息 | 夜话里谁接谁的话、小反应 |
| 仪式是否触发（双选公示、移情标记、零票累计、离场） | 触发后的场面怎么演 |

**不写死**：第 7 期最终谁确认关系、谁孤独收场——只写死「结局夜流程」；配对/移情路径由前六期选票与约束涌现（可复现种子）。

**选票约束（防塌戏）**

- 第 1–2 期：A↔B 互相心动**倾向高但不强制双选**；C 优先选 B；D 优先搅 A 或 B；F 不对 C 公开表白
- 第 3 期起：放开，但仍禁止「无动机的全员随机换人」；E 多数期可选「安全项」或不强攻主线
- 移情：仅已配对者可选；选了必须走公开标记名场面
- 离场：连续两期零票则离场（第 7 期除外）

**逐期表**

| 期 | 写死义务 | 白天约会（写死组合） | 竞猜焦点 | 信息门闸 | LLM 主发挥 |
|----|----------|----------------------|----------|----------|------------|
| **1** 亮相 | 六人自我介绍式亮相；第一次写下心动；HUD 一行赛制 | 随机/轮转均可，但 **A–B 不要首日独占长约会**（避免开局定终身） | **陆野（B）** | 公开人设齐；F–C 过往**零泄露** | 亮相口吻、第一印象独白 |
| **2** 火花 | 至少一组约会「明显有火花」；夜话有人打趣主磕 | **强制 A–B 一组**；其余两组：建议 C–D、E–F（可微调组别不改义务） | **沈晚（A）** | 观众应感到 A–B 有戏；C 对 B 的心思可露独白、台上可装没事 | 火花场面、打趣与回避 |
| **3** 不对劲 | 夜话**必须**出现一次不对劲：误会 / 试探越界 / 当众冷场（三选一由节拍骰或种子定类型，戏本身必有） | **强制 B–C 一组**（喂暗恋线）；A 与 D 或 E 一组（给搅局或嘴替镜头） | **许安安（C）** | 不对劲针对 A–B 或 B–C 三角，不提前爆 F–C | 不对劲怎么发生、谁圆场 |
| **4** 告急 | **二选一义务（种子定）**：① 某人积 1 零票告急，或 ② 已配对者出现移情苗头（独白级，可尚未投出）；夜话必须谈到「会不会有人走」 | 保人压力组：零票危险者尽量进双人约会；若无人危险则 **D 抢走 A 或 B 的一组** | **蒋予（D）** 或告急者（若有） | **F–C：允许第一缕痕迹**（旧称呼、欲言又止），不说明白 | 告急焦虑、搅局升级、痕迹怎么露 |
| **5** 公投夜 | **公投必发生**；结果**当场改变**当日后续（保人免零票 / 公开某人心动 / 强制约会覆盖原配对）；公投后夜话短、仪式重 | 若公投=强制约会 → 用公投指定组；否则按上期关系排 | 公投卡为主；副猜可取消 | 公投选项文案写死三选一；**不在本期讲清完整 F–C 故事** | 角色对公投结果的反应；被公开者的体面/破防 |
| **6** 洗牌 | 公投余波；**F–C 过往须让观众读懂**（可夜话戳破或双人摊牌）；心动前最后一次全面洗牌；可出现首次真·移情投票 | 优先 **C–F 一组**；A–B 视是否仍绑定数 | **谢衡（F）** 或 **周可（E）**（嘴替复盘向） | 暗线揭开；进入结局夜前关系牌面清晰 | 摊牌对白、余波站队 |
| **7** 结局夜 | 流程写死：已配对 → 确认或分开；未配对 → 最后心动 + 一句独白；可有一次公开告别；**无离场规则** | 可改为「最后白天自由接触」短镜，不强制任务 | **双焦或取消竞猜**（推荐：只猜「主磕线最终是否确认」二元题） | 全部秘密可落地；不新开支线 | 结局语气、是否复合/放过 |

**冷启动切片默认取材**：第 **3** 期夜话「不对劲」或第 **5** 期公投当场后果（与决策 #8 一致）。

## 6. 否决与边界（备忘）

| 方案 | 结论 |
|------|------|
| 对外仍主打「社会模拟器 / 上帝模式」 | 否——路人钩子不足 |
| 恋综做进开放小镇日常一条支线 | 否（第一季）——焦点稀释 |
| 用户当男/女主陪玩 | 否——滑向 AI 伴侣赛道 |
| 纯 scripted 短剧、无分叉 | 否——无 AI 壁垒；允许半 scripted 节拍，但不接受结局全写死 |
| 对标 AI 狼人杀陪玩 | 否——赛道挤；本提案保持观众席 |
| 冷启动先规则/先配人设 | 否——先戏后规则 |
| 配对即锁死到结局 | 否——允许移情但有代价 |
| 心动全程当场公开或全程保密 | 否——半公开 + 期末揭晓 |
| 第 1 期单独教学 | 否——正式赛制 + HUD 一行字 |
| 竞猜积分商城 / 重排行榜 | 否（第一季）——只保留对错 + 独白回放 |
| 结局后强推「自己开一季」 | 否（第一季）——三出口：高光 / 分叉 / 下季预告 |
| 第一季以 AgentTown 安装包为主入口 | 否——Web 播放器优先，3D 后置 |
| 起名时改关系拓扑 | 否——拓扑已定，改拓扑需再讨论 |
| 未经验证就改小镇主线排期 | 否——先最小可播 demo；过关后再拍是否插队 |
| Web 壳做成模拟器后台 | 否——只五面节目播放器 |
| 播控期并列侧栏堆面板 | 否——一屏一事，信息 ≤3 层 |
| 写死第 7 期最终 CP | 否——只写死结局流程；配对路径由选票涌现 |
| 前两期允许无约束乱选毁掉主磕 | 否——早期选票有倾向约束，防塌戏 |
