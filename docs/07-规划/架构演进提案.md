## 一、Sidecar 可迁移核（中长期）

桌面 spawn `python -m agentcore.sidecar` 跑**同一 `RuntimeEngine`**，stdio JSON-RPC 通信，仅把宿主端口（[执行引擎 §18.6](/docs/03-AI核心/执行引擎架构设计.md)）换为本地实现（SQLite / 内存 / in-proc），离线可降级。

- **价值**：本地执行 / 离线 / 隐私基础，云与本地同一引擎。
- **代价**：宿主端口面大、双实现维护成本高。
- **倾向**：中长期；新代码按「引擎面向宿主端口」组织留缝。

## 二、JSON-RPC 2.0 运行时协议（与 Sidecar 绑定决策）

用 JSON-RPC 承载整轮运行时（initialize / startTurn / resume / pause / cancel / respond…），事件映射为 notification，传输可换 stdio（sidecar）/ WS（云）。**注意非 MCP**（MCP 仍用于 Agent↔外部工具）。

- **价值**：云 / 桌面 / UI 一套代码，pause/resume/交互回值天然统一。
- **代价**：需把 SSE + HTTP 重构为协议层。
- **倾向**：与 Sidecar 绑定决策；否则暂缓。
