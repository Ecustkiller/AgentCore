## 二、待优化项（按杠杆分档）

### A. 提示词杠杆（一动改行为）

#### A1. 上游中间产物落盘许可 ✅ 已落地 · 本条退役

- 决策通过并落地：在 D 的「上游一环」分支补一条**许可式**文件名提示——零散发现写进 prose（自动转交下游）、值得落盘的大产物用 `file_write` + `findings-<角色>.md`（角色后缀防并行撞名）、切勿空路径，消除案例 2 残留的空路径白试并解锁文件指针。约束守住：不一刀切「上游必落盘」（笔记宜 prose）、也不「上游禁写文件」（代码类上游本该落盘），只做「想落盘就给名」的许可，不改 prose-vs-file 的判断权。
- 已解清单见「一、已落地」A1 行；落点决策（为何落在位置块上游分支而非 `_WORKER_DELIVERABLE_POLICY`）见「三、关键决策」。

### B. 度量 / 方法（没量化就别下结论）

#### B1. L3 / 角色越位的自动量化不可靠 🗂️

- **现象**：本轮用「数 task 里的编号列表 / Markdown 标题」当越位信号，**误报严重**——分不清「给调研员派的调研角度（=范围，CEO 该干的）」与「给写手定的章节结构（=越位）」；项目符号大纲还会漏判。
- **优化方向**：未来测 L3/越位用**人工读 task** 或更可靠的分类器（如用一次小 LLM 判「这段是需求范围还是章节结构」）。别再拿纯计数下结论。

#### B2. CEO「自研 vs 委派」的方差 🗂️

- **现象**：同一研究级请求两跑出现方差——run1（[案例 2 · D 前](/docs/07-规划/实测案例复盘.md)）CEO **即时 `delegate`、零自研**；run2（D 后）**先自做一轮检索探路**（自述「先做一轮轻量探路」，已摸出 Mem0 / Zep / A-Mem 等格局）再委派。核心提示「你自己的检索留给对话式直答与开工前**轻量探路**，不替团队扛调研腿脚活」**本就允许**轻量探路，故 run2 未必算违规；真正的风险是难判它何时从「探路」滑向「自扛调研腿脚」。
- **优化方向**：量化 CEO 在交付级研究任务里自研的轮数 / 工具数，划出「轻量探路」与「自扛腿脚」的界；越界再定是否收紧（先量化、后动词）。

### C. 健壮性（与内核 / 出网同源，留指针）

#### C1. web_search 引擎脆弱 🗂️

- **现象**：SearXNG 升级后仅 **360search** 恢复出结果；百度 / 搜狗 / 夸克仍 `Suspended: CAPTCHA`；`read_url` 偶发 `HTTP 521`（CSDN 等 Cloudflare 站点）。单引擎可用 = 脆。
- **指针**：与 [`实测案例复盘.md` 案例 1 #2](/docs/07-规划/实测案例复盘.md)「出网 / `read_url` 健壮性」**同源**，本文不重描述；优化（加可靠引擎 / 回退搜索 API / 出网降级）归那条。配置见 `deploy/searxng/settings.yml`。

## 三、关键决策（避免后人重提）

- **不对上游收回 file_write**：按角色文本判「是不是调研类」太脆；且会破坏「递指针不递全文」（代码类上游本该落盘）。改用 D 的拓扑提示约束「别做下游的活」，而非夺工具。
- **不裁剪 / 重写「原始用户请求」**：worker 真需要用户的原始意图；只在团队节点给它加一句**定调**（「老板交给整个团队的目标，不一定全是你的活」），单 worker 不加。
- **空路径不在工具层加自动兜底文件名**：那是「新增兜底逻辑」补丁绊线；守卫只做快速清晰报错，由模型自纠或退回 prose。
- **A1 落在位置块「上游一环」分支，不落 `_WORKER_DELIVERABLE_POLICY`**：空路径只发生在上游节点（终端环 / solo 本就在写最终文件、本就有名）；塞进全 worker 共享的 deliverable policy 会让终端 / solo 也念一遍无关的话。落在上游分支既精准，又能复用节点 role 拼出 `findings-<角色>.md`——一个既防空路径、又满足 sibling「别撞名」的文件名。提示给模板而非硬注入 `spec.role`（角色可能含中文 / 空格，硬拼成文件名不稳）。
- **D 选「统一团队位置块」而非外科手术式单点注入**：开发期可重构、概念更统一（sibling / 上游 / 下游收敛成一个「位置」），且为终端节点带来「你是最终作者」的所有权强化。
- **不再收紧 B（CEO 结构刹车）**：CEO 仍会给写手 task 放一个**通用**「结构:」脚手架（摘要/引言/主体/对比表/参考），但主体组织已用「可以…再…」让权。再收紧会让 CEO 连「要一张对比表」这种合理**需求**都不敢提；残留靠 A（worker 自主）+ D（终端所有权）在接收端兜。
