## 一、验证结论：Tier 1 + Tier 2 已落地（live + 重载一致）

逐项核到源码，链路三段（直播投影 → 持久化 → 重载回放）均闭环：

| 项 | 直播 | 持久化 + 重载 | 状态 |
|---|---|---|---|
| 回合 **token 用量**（输入/输出/思考/缓存命中·未命中） | `message_end.usage` → `attachTurnMetaToLastMessage`（`stores/conversation.ts` ~835）→ 气泡 meta 行（`MessageBubble.tsx` ~1111） | 写助手行 `usage` 列（`conversation/service.py` ~777）→ `MessageDetail.usage`（`schemas/messages.py` ~325 + `_usage_from_row`）→ `toMessage`（`services/messages.ts` ~152） | ✅ |
| 回合 **轮次 `rounds`** | `message_end.rounds` → 同上 → `N 轮`（>1，`MessageBubble.tsx` ~1121） | 同 `usage` 列 → `MessageDetail.rounds` → `toMessage` ~153 | ✅ |
| **结束原因 chip**（`max_rounds`/`degraded`/`unproductive`/`cancelled`） | `finishReasonChip`（`MessageBubble.tsx` 1014–1045，四态齐全） | journal `turn_end` 持久化 `finish_reason` → `runs.finish_reason` → `toMessage` ~144（单/多 Agent 都回放） | ✅ |
| **报错回合 error 卡**重载回放 | `error` SSE → `attachErrorToLastMessage` | 异常回合合成最小 journal（`service.py` ~748）→ `RunError`（`schemas/messages.py` 273）→ `toMessage` ~147 | ✅ |
| 多 Agent 回合成本/用量 | 成本归团队卡状态条；token/轮次补在气泡 meta（所有回合都显） | 同上 | ✅ |
| **辩论 motion + 主持人**渲染 | `DebateTopicHeader`（`DebateCompare.tsx` 170–206，辩题 + 主持人裁决入口） | 随 `execution.debate` 回放，无需额外持久化 | ✅ |
| **辩论逐轮**实时叠加 + 重载 | `debate_round[_started]` → `debateRounds`（`conformanceFold.ts` 204–225，巡检同源） | 随 journal 回放 | ✅ |
| **checkpoint 富菜单**（assumptions/questions/style_options） | `CheckpointCard`（菜单 274–349）；`checkpointsFromEvents`（`conversation.ts` 72–103）保 3 类字段 | 事件入 journal → 重载 `DormantCheckpoint`（555–607）渲染起步计划 + 重点问题 | ✅ |

**结论**：用户判断正确——Tier 1、Tier 2 都已落地，且 04-前端 文档已同步为现状。
