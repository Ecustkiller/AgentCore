### 模块职责边界

| 模块 | 职责 | 依赖 | 不依赖 |
|------|------|------|--------|
| `api/` | HTTP 入口，参数验证，SSE 响应 | schemas, conversation, middleware | runtime, llm, tools |
| `middleware/` | JWT 认证、限流 | db, core | 业务模块 |
| `conversation/` | 对话生命周期管理，stream_chat 入口 | runtime, orchestrator, memory, db | api |
| `runtime/` | ReAct 循环、Run 调度、Turn Journal、交互原语 | llm, tools, core | orchestrator, conversation, api |
| `orchestrator/` | 意图理解，任务分解，计划生成，检查点审视 | llm, core | runtime, conversation, api |
| `llm/` | LLM API 调用封装 | core | 所有其他模块 |
| `tools/` | 工具注册、执行、审批 | sandbox, core | 所有其他模块 |
| `memory/` | 会话摘要、用户偏好、上下文装配 | llm, db, core | runtime, orchestrator |
| `db/` | 数据持久化 | core | 所有其他模块 |
| `core/` | 共享类型和工具 | 无 | 所有其他模块 |

### 调用链路

```
POST /v1/conversations/{id}/messages
  → api.routes.conversations.send_message()
  → conversation.service.stream_chat()              # 入口
      → runtime.pipeline.run()                       # ChatPipeline
          │
          ├─ [Prepare]
          │   → runtime.resolve.resolve_agent()       # 组装 prompt、选模型、工具集
          │   → memory.context_builder.build()        # 注入上下文
          │   → orchestrator.planner.plan()            # 生成协作计划（如需多 Agent）
          │
          ├─ [Execute]
          │   → runtime.engine.react_loop()            # ReAct 主循环
          │       → llm.deepseek.stream()              # 调用 LLM
          │       → tools.registry.execute()           # 执行工具
          │       → runtime.loop_controller.evaluate()  # 收敛判定
          │       → runtime.runs.schedule()             # 多 Agent Run 调度
          │       → runtime.journal.append()            # 事实记录
          │       → runtime.events.emit()               # SSE 推送
          │       → runtime.interactions.wait()          # 审批/ask_user 挂起
          │
          └─ [Finalize]
              → db.repositories.save()                 # 持久化消息
              → memory.conversation_summary.generate()  # 会话摘要
  → SSE StreamingResponse → Client
```

### 前端组织原则

1. **features/ 按业务拆分**：每个 feature 自包含（组件 + 逻辑），可独立开发
2. **stores/ 集中管理**：因为多个 feature 共享状态（如 execution 状态被 chat 和 graph 同时消费）
3. **types/ 自动生成**：`api.generated.ts` 由后端 OpenAPI schema 自动生成，不手动编辑
4. **components/ui/ = shadcn/ui**：基础组件从 shadcn/ui 添加，保持源码可控

## 六、开发命令

```bash
# 后端
cd apps/server
uv run uvicorn agentcore.main:app --reload      # 开发服务器
uv run pytest                                    # 运行测试
uv run ruff check .                              # lint

# 前端
cd apps/desktop
pnpm dev                                         # electron-vite 开发模式
pnpm test                                        # Vitest
pnpm build                                       # 构建

# 类型同步
cd packages/scripts
pnpm generate-types                              # OpenAPI → TypeScript
```
